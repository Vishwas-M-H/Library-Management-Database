## Prompt 1 — Library Management System

> **Development approach:** Use GitHub Copilot, Claude Code, ChatGPT or VS Code
> Chat. Build the solution primarily through prompting and AI-assisted
> development.
>
> **Business scenario:** ABC Engineering College has a library containing
> hundreds of books across categories such as Programming, Artificial
> Intelligence, Data Science, Mathematics, Electronics, and Management.
> Librarians currently maintain records in spreadsheets and need a simple web
> app to record book information, view the collection, and generate inventory
> statistics.
>
> **Objective:** Build a Library Management System using Python, Streamlit,
> SQLite, a virtual environment, and Git.
>
> **Database:** Create `library.db` with a `books` table containing `book_id`,
> `book_title`, `author_name`, `category`, and `available_copies`.
>
> **Features:** Add a book (title, author, category, available copies); view
> books; show total books available; show the most available book; show a
> category summary.
>
> **Expected workflow:** Requirement analysis, database design, application
> generation, testing, documentation, and Git operations.
>
> **Submission guideline:** Maintain all prompts used during development.
